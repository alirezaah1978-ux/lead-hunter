# 🔀 n8n در برابر GitHub Actions — کدام برای چه کاری؟ (و وضعیت ما)

## ۰) جواب صریح به «چرا تا حالا از n8n استفاده نکردی؟»

**استفاده کردم؟ نه — و دو دلیل واقعی داشت، نه لجبازی:**
1. **n8n نمی‌تواند اینجا ۲۴/۷ بماند.** در این پلن، من فقط در لحظه‌ی گفتگو اجرا می‌شوم؛ پروسه‌ای که راه بیندازم بعد از پایان پیام نگه داشته نمی‌شود. n8n هم یک پروسه است (نصب سنگین ~۵۰۰MB+ و نیاز به سرور همیشه‌روشن). **GitHub Actions رایگان و ۲۴/۷ بود → ستون اصلی شد.**
2. **n8n اکانت/سرور می‌خواهد:** نسخه‌ی ابری ثبت‌نام و پول لازم دارد و من نمی‌توانم اکانت بسازم؛ نسخه‌ی self-hosted هم به یک سرور یا سیستم روشن (کامپیوتر خودت) نیاز دارد.
**اما از این به بعد:** هر ورک‌فلویی که بسازم، **نسخه‌ی JSON آماده‌ی ایمپورت n8n** هم همراهش می‌سازم (دو نمونه همین حالا در `engine/n8n/`). اگر یک n8n رو کنی (کامپیوتر خودت یا VPS)، آن‌ها را import می‌کنی و تمام.

## ۱) جدول مقایسه

| معیار | GitHub Actions | n8n |
|---|---|---|
| هزینه | رایگان (پابلیک، نامحدود) | self-hosted رایگان · ابری از ~€20/ماه |
| ۲۴/۷ | ✅ بدون سرور، ابری | فقط با سرور روشن (VPS ~€3–5 یا کامپیوتر خودت) |
| دقت زمان‌بندی | cron با لرزش ±۱۵ دقیقه، بعد از ~۶۰ روز بی‌کاری خاموش می‌شود | cron دقیق (سرور خودت) — ماندگار |
| تریگر لحظه‌ای (Webhook/دکمه) | ❌ (بدون سرور نداریم) | ✅ بهترین قابلیت — دکمه، فرم، رویداد |
| ادغام با سرویس‌ها | فقط با کد (API زدن) | ✅ ۴۰۰+ نود آماده (گوگل‌شیت، تلگرام، دیوار، ایمیل، دیتابیس، AI...) |
| ویرایش توسط تو (بدون کد) | ❌ YAML | ✅ کشیدن‌و‌رهاکردن روی صفحه |
| لاگ و دیباگ | لاگ‌ها موقت، دیباگ از راه دور | اجراها را قدم‌به‌قدم می‌بینی؛ خطا را با چشم می‌بینی و دستی Test می‌گیری |
| ورژن‌کنترل | ✅ عالی (کل کد در گیت) | ⚠️ ضعیف (JSON ایمپورت/اکسپورت) |
| قدرت کد دلخواه (Python ما) | ✅ اجرای کامل | ⚠️ فقط در حالت self-hosted (نود Execute Command) یا تقلید با Code/HTTP |
| امنیت توکن | GitHub Secrets عالی | Credentials داخلی خوب |
| وابستگی به من | کار می‌کند بدون تو | برای تغییر، یا خودت یا من باید JSON بدهم |

## ۲) تقسیم کار پیشنهادی (بهترین حالت)

| کار | اجراکننده |
|---|---|
| اسکن‌های سنگین ۲۴/۷ (رهیاب، کانال، پست خودکار) | **GitHub Actions** (همین که هست) |
| رادار tgju + هشدار نوسان | هر دو ممکن؛ نسخه‌ی n8n آماده است (`رادار-tgju.json`) |
| دستور گرفتن از تو در تلگرام («وضعیت»، «فرصت‌ها»، «پست کن») | **n8n** (تریگر تلگرام — کاری که GH نمی‌تواند) |
| وصل‌شدن به گوگل‌شیت/CRM/ایمیل مشتری | **n8n** |
| گزارش‌گیری خودکار + ارسال به مشتری | n8n روی GH |
| نسخه/تاریخ کد | **GitHub** |

## ۳) دو فایل آماده‌ی ایمپورت (ساخته شد)

| فایل | چه می‌کند | پیش‌نیاز |
|---|---|---|
| `engine/n8n/رادار-tgju.json` | هر ۳۰ دقیقه دلار/طلا/سکه را می‌خواند و به تلگرام می‌فرستد | فقط credential تلگرام + `TELEGRAM_CHAT_ID` |
| `engine/n8n/کانال-۳-پست.json` | ۳ آلارم روزانه → دیسپچ ورک‌فلوی کانال روی GitHub | PAT گیت‌هاب (همان که داری) |

**مراحل ایمپورت:** n8n → Workflows → Import from File → فایل JSON → جای `REPLACE_WITH...` را پر کن → Active کن.
**هوای ساعت را داشته باش:** n8n با تایم‌زون سرور خودت کار می‌کند؛ برای تهران `TZ=Asia/Tehran` ست کن (یا ساعت‌ها را جابه‌جا کن).

## ۴) جواب کوتاه برای تصمیم

- **الان:** GH را نگه می‌داریم (چون تنها گزینه‌ی ۲۴/۷ رایگان بدون سرور است).
- **به‌محض اینکه n8n روی کامپیوتر/VPS خودت بالا آمد:** دو فایل بالا را ایمپورت کن؛ از آن به بعد **کنترل و ویرایش دستِ خودت** است و من JSON هر اتوماسیون جدید را تحویل می‌دهم. حتی می‌توانم دخواست‌های تو را به‌صورت فرمان تلگرامی به n8n وصل کنم («فرصت‌ها» بفرست → پاسخ فوری).
