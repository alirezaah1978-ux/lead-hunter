# 🪜 قدم به قدم: سرور رایگان ۲۴/۷ (بدون کارت بانکی) — Hugging Face Space

> **چرا این؟** از بین ۱۴ سرویس بررسی‌شده (Render، Koyeb، Fly.io، Northflank…)، این تنها جایی است که **کارت بانکی نمی‌خواهد**، با **حساب گیت‌هاب** ساخته می‌شود، **۲ هسته + ۱۶GB رم رایگان** می‌دهد و **n8n هم رویش اجرا می‌شود**. Render فقط ۵۱۲MB می‌دهد (n8n در آن نفس‌نفس می‌زند)، Koyeb و Northflank کارت می‌خواهند.

**آدرسی که به دست می‌آید:** `https://<نام‌کاربری‌تو>-rahyab.hf.space`
**نتیجه:** فرمان تلگرام → **پاسخ فوری** (نه ۱۰ دقیقه)، پنل وضعیت، و نگه‌داشتن ۲۴/۷ با پینگ خودکار.

---

## گام ۱ — حساب (با گیت‌هاب، بدون کارت)
1. برو به 👉 **huggingface.co/join**
2. روی **Continue with GitHub** بزن → اجازه بده
3. ایمیل تأیید می‌آید → تأیید کن (فقط همین. کارت و موبایل لازم نیست)

## گام ۲ — ساخت Space
1. برو به 👉 **huggingface.co/new-space**
2. پر کن:
   - **Owner:** خودت
   - **Space name:** `rahyab` (کوچک، انگلیسی)
   - **License:** خالی بگذار
   - **Select the Space SDK:** ✅ **Docker** → **Blank**
   - **Space hardware:** ✅ **CPU basic · FREE** (قابل اطمینان بزن)
   - **Visibility:** **Public** (Private فقط با اشتراک PRO است؛ رمزها در Secrets می‌مانند، پس امن است)
3. **Create Space**

## گام ۳ — آپلود فایل‌ها (۳ فایل)
در صفحه‌ی Space → تب **Files** → دکمه **Contribute** → **Upload files**
این سه فایل را از پوشه‌ی `engine/hf` بکش و رها کن:
- `app.py`
- `Dockerfile`
- `README.md` ← ⚠️ **حتماً همین README** (تنظیمات `sdk: docker` داخلش است)
→ **Commit** (بدون پیام هم شود، مشکلی نیست)

## گام ۴ — رمزها (Secrets)
Space → **Settings** → پایین صفحه **Variables and secrets** → **New secret** — این ۴ تا را یکی‌یکی اضافه کن:

| نام (Name) | مقدار (Value) |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن ربات (@AliAutoAssistant_bot در BotFather) |
| `TELEGRAM_CHAT_ID` | `7662582059` |
| `WEBHOOK_SECRET` | خودت بساز: ۲۰ حرف تصادفی انگلیسی — این رمزِ لینک وب‌هوک است |
| `GH_PAT` | همان PAT گیت‌هاب (برای فرمان‌های قیمت/فرصت/اسکن) |
| `GH_REPO` | `alirezaah1978-ux/lead-hunter` |

## گام ۵ — ساخت خودکار (۲–۴ دقیقه)
Space خودش شروع به Build می‌کند (بالای صفحه: Building ▶ سپس **Running** 🟢).
وقتی سبز شد → آدرس بالا را در مرورگر باز کن → **پنل رهیاب** (رادار زنده + وضعیت) باید بیاید.

## گام ۶ — وصل کردن ربات به سرور (یک‌بار، ۱۰ ثانیه)
یک لینک را در مرورگر باز کن (جای `<TOKEN>` و `<SECRET>` را بگذار):
```
https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://<USERNAME>-rahyab.hf.space/webhook/<SECRET>
```
باید ببینی: `{"ok":true,"result":true,"description":"Webhook was set"}`

## گام ۷ — تست 🎉
در تلگرام به ربات خودت بنویس **رادار** → همان لحظه جواب می‌دهد.
تست کن: **راهنما · وضعیت · قیمت · فرصت · اسکن**

## گام ۸ — ۲۴/۷ شدن (پینگ ضدخواب)
1. در گیت‌هاب: `lead-hunter` → **Settings → Secrets and variables → Actions → New repository secret**
2. نام: `SPACE_URL` — مقدار: `https://<USERNAME>-rahyab.hf.space`
3. تمام. ورک‌فلوی `keepalive.yml` (که ساختیم) هر ۳۰ دقیقه Space را بیدار نگه می‌دارد → عملاً ۲۴/۷.

## گام ۹ (اختیاری) — خودِ n8n روی Space دوم
اگر n8n را هم می‌خواهی (ویرایش بصری ورک‌فلو):
1. یک Space دوم بساز (مثل گام ۲)
2. فایل `Dockerfile-n8n` را (در پوشه‌ی `engine/hf`) به‌عنوان **Dockerfile** آپلود کن (با یک README در همان قالب)
3. بازش کن → حساب مالک n8n را بساز → از من فایل‌های JSON ایمپورت را بگیر
⚠️ بدون دیتابیس بیرونی، ورک‌فلوها بعد از بازسازی پاک می‌شوند — برای ماندگاری بگو تا وصلش کنیم به Postgres رایگان.
> ترتیب پیشنهادی: **اول Space فرمان (گام ۱–۸)** — چون کنترل فوری می‌دهد؛ n8n بعداً.

## ❓ اگر گیر کردی
| مشکل | راه‌حل |
|---|---|
| Space سبز نشد | تب **Logs** را ببین؛ معمولاً README اشتباه آپلود شده (باید فرانت‌متر `sdk: docker` داشته باشد) |
| وب‌هوک OK نشد | آدرس باید کامل باشد: `.../webhook/<SECRET>` و `<USERNAME>` را اشتباه/کوچک نوشته باشی — نام کاربری HF حروف کوچک دارد |
| رادار جواب نمی‌دهد | در Space → Settings → Logs؛ «no token» یعنی `TELEGRAM_BOT_TOKEN` ست نشده |
| فرمان قیمت: «GH_PAT ست کن» | سکرت `GH_PAT` را اضافه کن (همان توکن گیت‌هاب) |
