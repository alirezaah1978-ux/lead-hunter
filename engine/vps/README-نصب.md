# 🚀 راه‌اندازی سرور ۲۴/۷ رایگان (Oracle) + n8n + Windmill — زیر ۱۵ دقیقه

> من نمی‌توانم حساب ابری بسازم (کارت/موبایل/هویت تو لازم است).「نصب» دقیقاً همین است: تو ۶ کلیک می‌زنی، من بقیه‌ی کار را با یک اسکریپت آماده کرده‌ام.

## گام ۱ — ساخت اکانت Oracle (۵ دقیقه)
1. `cloud.oracle.com` → **Start for free** (ایمیل + موبایل + کارت برای احراز — چیزی کم نمی‌شود)
2. Region: **Germany Central (Frankfurt)** یا نزدیک‌ترین — برای تو (آلمان) فرانکفورت عالی است

## گام ۲ — ساخت سرور (۳ دقیقه)
1. منوی ☰ → **Compute → Instances → Create instance**
2. **Image:** Ubuntu **24.04** (نسخه ARM/aarch64)
3. **Shape:** Change shape → **Ampere → VM.Standard.A1.Flex** → **4 OCPU / 24 GB**
4. کلید SSH: **Generate a key pair** → کلید خصوصی را دانلود کن (فایل `ssh-key-….key`)
5. **Create** → ۱ دقیقه صبر → **Public IP** را کپی کن
   - ⚠ اگر «Out of host capacity» داد: Availability Domain دیگر را امتحان کن یا چند ساعت بعد دوباره (بعد از ساخت، من اسکریپت تکرارخودکار می‌دهم)

## گام ۳ — باز کردن پورت‌ها در کنسول (۱ دقیقه)
**Networking → Virtual Cloud Networks → vcn → Security Lists → Default → Add Ingress Rules**
دو قاعده با Source `0.0.0.0/0`: پورت **5678** و پورت **8000**

## گام ۴ — اتصال به سرور
از لپ‌تاپ:
```
ssh -i کلید.key ubuntu@IP-سرور
```
(ویندوز: Windows Terminal همین دستور کار می‌کند؛ اگر خطای permission داد: `icacls کلید.key /inheritance:r`)

## گام ۵ — نصب یک‌مرحله‌ای (همه‌چیز خودکار)
فایل `نصب-یکخطی.sh` را باز کن → **کل متن را کپی کن** → در ترمینال سرور **پیست کن** → Enter.
(یا: از من بخواه فایل را در گیت‌هاب خودت بگذارم تا با یک `curl | bash` اجرا کنی.)

۴–۸ دقیقه بعد:
- 🟢 **n8n** → `http://IP:5678` (اولین بازشدن: ساخت حساب مالک)
- 🟢 **Windmill** → `http://IP:8000`

## گام ۶ — برگرد و به من بگو «سرور بالا آمد»
من همان لحظه:
1. فایل‌های JSON ایمپورت را کامل می‌کنم (رادار tgju + کانال ۳ پست + اسکن عمره)
2. Webhook تلگرام را وصل می‌کنم تا **فرمان بدهی و جواب بگیری** («فرصت‌ها» → جواب فوری)
3. cron دقیق (بدون لرزش ±۱۵دقیقه‌ی گیت‌هاب) فعال می‌شود
