# ۰۲ — اولین تماس با فروشنده (لید ورودی از دیوار/تلگرام/اینستاگرام)

> در تماس اول **حرفی از پورسانت نزن**. تماس اول فقط دو کار دارد:
> (۱) موجودی و قیمت واقعی را بفهم، (۲) اعتماد کوتاه بساز.
> پورسانت را وقتی می‌گویی که خریدار واقعی روی میز داری.

## پیام اول (تلگرام / واتساپ / DM) — کوتاه، بدون اسپم
```
سلام، وقت‌تون بخیر 🌱
درباره‌ی آگهی «[عنوان آگهی]» تماس گرفتم.
من تأمین‌کننده‌ی خریدار هستم (سمت تقاضا کار می‌کنم)، دنبال [کالا + مشخصات دقیق + مقدار] هستم.
دو سؤال کوتاه:
۱) الان موجودی واقعی چقدره؟ ۲) کمترین قیمت برای این حجم چنده و شرایط تسویه‌تون چیه؟
اگر رقم‌ها بخوره، من خودم طرف خریدار را هماهنگ می‌کنم.
ممنون
```

## چک‌لیست تماس (انجام‌شده‌ها را تیک بزن)
- [ ] موجودی **واقعی** است یا «موجود انبار دیگری»؟ (سؤال کلیدی؛ خیلی‌ها فقط دلال‌اند)
- [ ] قیمت واحد برای حجم خریدار + آیا تخفیف حجمی دارد؟
- [ ] مبدأ بار، هزینه‌ی حمل، چه کسی حمل را می‌گیرد؟
- [ ] فاکتور رسمی می‌دهد؟ مهر شرکتی دارد؟
- [ ] شرایط تسویه (نقد / ۳۰ روزه / فوری با تخفیف)
- [ ] نمونه/عکس/آزمایشگاه قابل ارائه؟
- [ ] آیا **قبلاً با واسطه کار کرده**؟ (اگر بله و بد تجربه داشته، اینجا مقاومت می‌شود)
- [ ] اسم و شماره‌ی مالک/تصمیم‌گیرنده (اگر خودش نیست)

## اگر گفت «واسطه نمی‌خوام»
دو جواب استاندارد:
1. «من دارم سمت خریدار را می‌آورم؛ یعنی کاری که خودتان باید ۲ هفته انجام بدهید را من انجام می‌دهم.
   هزینه‌ای هم به شما تحمیل نمی‌شود؛ فقط از فروشنده‌ی برنده (یعنی شما) پورسانت می‌گیرم.»
2. اگر باز مقاومت کرد: **تمام کن و برو سراغ نفر بعد.** فروشنده‌ی بدقلق، عمر پروژه را می‌خورد.
   ما دنبال «تأمین‌کننده‌ی همکار» هستیم، نه هر آگهی‌دهنده.

## ثبت در CRM
ستون‌ها: `آگهی / منبع / قیمت واقعی / موجودی واقعی / حمل / تسویه / نگرش (۰-۵) / وضعیت`
وضعیت‌ها: `NEW → CONTACTED → QUOTED → MATCHED → MEETING → WON / LOST / DEAD`
